# tkinterdnd2未導入時の起動対応（2026-10-27）

`requirements.txt` には tkinterdnd2 が含まれています。旧版の仮想環境が残っている場合や、セットアップしたPythonとは別のPythonから main.py を開いた場合、未導入エラーになることがあります。ユーザーのWindows環境での発生条件は未確認です。

## 変更

- main.py はGUIを読み込む前に必要なパッケージを確認します。不足時は起動したPythonのパスと、そのPythonへ導入するコマンドを表示します。Windowsのウィンドウ起動ではダイアログも表示します。
- start.bat はアプリ専用の .venv を使います。依存パッケージの確認に失敗した場合は requirements.txt の導入を実行し、再確認してから起動します。修復失敗時は起動を停止します。修復にはネット接続が必要です。
- setup.bat もインストール後に依存関係を確認します。
- EXE版の不足では、pipではなく _internal を含むフォルダー全体の再展開・再ビルドを案内します。
- READMEにソース版・EXE版それぞれの対処を追記しました。

## 検証

- tkinterdnd2が未導入の実環境で main.py --check-dependencies が終了コード1となり、導入方法を表示することを確認。
- requirements-build.txt の依存を一時ディレクトリへ導入後、同じコマンドが終了コード0となることを確認。
- 起動関連の新規7テストと、既存の配布構成4テストが全件成功、スキップ0。
- Windows COMの確認順、ウィンドウ起動で標準エラー出力がない場合の通知、EXE向け案内、正常時のみGUIを呼ぶことをモックで確認。
- PyInstallerの収集フックでWindows x64/x86/ARM64用のTkDND DLLとTclが同梱対象にあることを確認。
- Pythonコンパイル成功。

Linux上での検証です。Windowsバッチの実実行、EXEの実ビルド・起動、実Outlookの操作は今回実施していません。既存185件の全体テストは前回監査の結果であり、今回の追加7件と合算して再実行済みとは扱いません。
